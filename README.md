# Facility Management System - "FCM_uwu"

A unified facility management platform combining a Flutter frontend for residents/staff with a Node.js/SQLite backend for operations and AI analysis.

## Project Structure

```text
/
├── backend/          # Node.js + Express backend
│   ├── src/          # Source files 
│   │   ├── controllers/# API endpoint controllers (auth, chat, repair)
│   │   ├── services/   # Business logic and AI interaction
│   │   └── database.ts # SQLite database configuration
│   └── seed_db.ts    # Seed script for initial database state
│
├── frontend/
│   ├── FCM_uwu/      # Primary User-facing Flutter Application
│   │   └── lib/      # Core UI, Theme, and Presentation files
│   └── db_react/     # Legacy/Secondary React project
```

## Core Features

- **AI Chat Assistant**: Provides residents with conversational support and extracts maintenance intents into actionable JSON objects. Includes real-time voice dictation with visual sound spectrum feedback and draft persistence.
- **Automated Request Routing**: Tasks created by the AI are formatted, scheduled, and injected directly into the active SQLite database seamlessly.
- **Interactive UI**: A modern dashboard containing 3D rendering elements and persistent chat action states.

## Setup Instructions

### Backend Configuration
1. Navigate to `/backend`.
2. Configure your Environment Variables (`.env`) for the Database, JWT Secrets, and external AI Provider APIs.
3. Start the primary node instance using `npm run dev`.

### Frontend Configuration
1. Navigate to `/frontend/FCM_uwu`.
2. Verify that Flutter is installed (`flutter doctor`).
3. Launch with `flutter run -d chrome` or your preferred emulator.
